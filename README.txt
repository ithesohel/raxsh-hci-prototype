RAXSH PROTOTYPE

LOCAL RUN (Windows)
1. Double-click run_local.bat
2. Open http://localhost:8000 in Chrome/Edge
3. Keep the terminal window open during the demo

LOCAL RUN (macOS/Linux)
1. Double-click/run run_local.command, or run: python3 -m http.server 8000
2. Open http://localhost:8000

GITHUB PAGES
Upload all files and folders in this package to the root of a GitHub repository.
Then go to Settings > Pages > Deploy from a branch > main > /(root) > Save.
